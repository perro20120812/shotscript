## 四、构建方式（开发者）

```bash
# 安装依赖
npm install

# 本地调试运行
npm start

# 打包 macOS DMG（arm64）
npm run dist:mac

# 打包 Windows 安装包（x64）
npm run dist:win
```

- 打包产物输出至 `dist/` 目录；
- Windows 原生依赖需在 Windows 机器执行 `npm install` 拉取 win-x64 包后重建；
- 产物目录结构：`main/`（主进程）、`preload/`（预加载）、`renderer/`（界面）、
  `src/`（渲染逻辑）、`rust/`（原生激活模块，Rust 源码 + 构建产物）。
