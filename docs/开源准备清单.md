## ✅ 二、激活码体系安全确认

| 项 | 状态 | 说明 |
|---|---|---|
| 私钥 `private.pem` | 仅开发者本机 | 不入库、不分发，发布前建议重新 `generate-keypair` 并妥善备份 |
| 公钥 `public.pem` | 可入库 | 内嵌进 `shotscript_license.node`，免费版源码不含验签逻辑（原生模块） |
| 签发工具 `shotscript-tool` | 不随源码发布 | 位于 `rust/crates/tool`，其产物在 `rust/target`（已忽略） |
| 免费版无激活能力 | 安全 | 激活校验在 Rust 原生模块内，免费版仅能调用「未激活」路径 |

> 结论：即使完全开源免费版，攻击者也无法用源码绕过或伪造激活码（验签在闭源原生模块 + 公钥内嵌完成）。

## ✅ 三、README.md（发布前必须编写完整）

建议包含以下章节（Markdown）：

1. **项目简介**：ShotScript 剧本工坊 —— 面向视频创作者的开源 AI 文案工具（黄金 3 秒钩子 / 口播文案 / 本地 AI 润色）。
2. **免费版功能**：种子引擎固定模板、规则分镜、基础文案生成。
3. **Pro 版说明**：种子引擎无限模板（含黄金 3 秒钩子强度体系）、本地 AI 润色（闭源本地推理引擎，离线运行）、多平台批量导出、Rust RSA 激活校验。
   - 注明 Pro 为**闭源付费版**，激活码校验在原生模块内，免费版源码不含激活逻辑。
4. **纯净模式**：设置页「隐藏 Pro 推广」开关说明。
5. **安装**：指向 `docs/安装与分发指南.md`（macOS DMG / Windows EXE 下载与安装、未签名放行指引）。
6. **构建**（开发者自建）：
   ```bash
   npm install
   npm start               # 开发运行
   npm run dist:mac        # 打包 macOS DMG
   npm run dist:win        # 打包 Windows EXE（Windows 机器上执行）
   ```
   - 原生模块构建：`cd rust && cargo build --release -p shotscript-tool`（详见 `rust/README.md`）。
7. **许可证**：MIT。
   - 根目录必须放置 `LICENSE` 文件（MIT 全文）。

## ✅ 四、GitHub 发布 Release 步骤

### 1. 初始化与推送
