## 三、激活码自动发放流程（付款 → 解锁闭环）

> 激活码由开发者本机生成（离线 RSA-SHA256 签名，一人一码），通过各平台「自动发货」机制派发。

```
┌─────────┐   ① 用户付款     ┌──────────────┐
│ 用户/创作者 │ ─────────────▶ │ 收款平台        │
└─────────┘                   │（爱发电 / LS）  │
      ▲                       └──────┬───────┘
      │                              │ ② 平台自动发货
      │                              ▼
      │                    ┌─────────────────┐
      │                    │ 自动发送激活码      │（卡密 / License Key）
      │                    └────────┬────────┘
      │                             │ ③ 用户在应用内输入
      │                             ▼
      │                   ┌────────────────────┐
      │                   │ ShotScript 设置页     │
      │                   │ “输入激活码并激活”      │
      │                   └────────┬───────────┘
      │                            │ ④ Rust RSA-SHA256 验签
      │                            ▼
      │                   ┌────────────────────┐
      │                   │ 验签通过 → 解锁 Pro    │
      │                   │ 验签失败 → 提示无效    │
      └───────────────────┴────────────────────┘
        ⑥ 本地授权持久化，启动复验
```

**各环节说明：**

1. **付款**：用户在爱发电 / Lemon Squeezy 完成支付；
2. **自动发货**：平台检测到订单成功后，立即向用户发送激活码（爱发电发卡密 / LS 发 License Key）；
3. **输入激活码**：用户打开应用 → 设置页 → 输入激活码；
4. **Rust 验签解锁**：应用调用原生模块，用内嵌公钥对激活码做 RSA-SHA256 验签；
5. **解锁 Pro**：验签通过即解锁种子引擎无限模板 / 本地 AI 润色 / 多平台批量导出；
6. **持久化与复验**：授权写入本地文件，每次启动自动复验（验签 + 有效期检查），
   篡改 / 过期 / 不匹配自动清除授权回退未激活。

## 四、激活码签发方式（供开发者使用）

- 激活码生成工具位于工程内（Rust 侧签发器，私钥仅存本机，不入库、不上传）；
- 生成规则：`(版本号 + 授权人标识 + 随机盐) → RSA 签名 → Base64 编码`，一人一码、不可伪造；
- 公钥硬编码于原生模块内，随应用分发，可接受外部审计；
- 批量签发：可按批次生成 N 个激活码导出为文本，导入爱发电库存 / LS License Key 池。
