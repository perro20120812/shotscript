# ShotScript 剧本工坊 · 安装与分发指南

> 版本：0.1.0 ｜ 分发形态：macOS DMG + Windows NSIS 安装包 ｜ 签名状态：未签名（免费分发）

---

## 一、分发包清单（本目录 `dist/`）

| 平台 | 文件 | 大小 | 说明 |
|---|---|---|---|
| macOS (Apple Silicon) | `ShotScript 剧本工坊-0.1.0-arm64.dmg` | 约 145 MB | 拖拽安装，未签名 |
| Windows x64 | `ShotScript 剧本工坊-Setup-0.1.0-x64.exe` | 约 130 MB | NSIS 安装器，未签名 |

> macOS 仅产出 arm64（Apple Silicon）版本：应用依赖 Rust 原生激活模块与本地 AI 推理引擎的
> arm64 预编译二进制，均面向 arm64 构建。Intel Mac 需另构建 `mac-x64` 产物。

## 二、macOS 安装步骤

### 1. 打开 DMG
双击 `ShotScript 剧本工坊-0.1.0-arm64.dmg`，挂载后出现安装窗口。

### 2. 拖入 Applications
把 `ShotScript 剧本工坊.app` 拖到右侧的 `Applications` 文件夹图标上即完成安装。

### 3. 首次启动：绕过 Gatekeeper（未签名应用）
由于未购买 Apple Developer 证书（$99/年）签名，系统会拦截「无法打开，因为无法验证开发者」。
**首次打开方式（任选其一）：**

- **右键打开（推荐）**：在「应用程序」中找到 ShotScript，按住 `Control` 单击（或双指点击）→ 选择「打开」→ 在弹出的对话框中点击「打开」。
- **系统设置放行**：若右键打开仍被拦，进入 `系统设置 → 隐私与安全性`，滚动到「安全性」区域，点击「仍要打开」。

> 只需首次放行一次，之后可正常双击启动。

### 4. 纯净模式提示
打开应用后，进入「设置」页可开启「隐藏 Pro 推广」开关（纯净模式）。该开关持久化保存，
开启后导航栏的 Pro 入口、角标、升级弹窗等推广触点全部隐藏，Pro 功能保持锁定；需要时可在
设置页低调重新激活或关闭纯净模式。

## 三、Windows 安装步骤

### 1. 运行安装包
双击 `ShotScript 剧本工坊-Setup-0.1.0-x64.exe`，按向导选择安装目录与是否创建桌面快捷方式。

### 2. 未签名提示
SmartScreen 可能提示「Windows 已保护你的电脑」，点击「更多信息 → 仍要运行」即可继续安装。

### 3. 运行
安装完成后从开始菜单或桌面快捷方式启动。

### 4. 纯净模式
同 macOS，进入「设置」页开启「隐藏 Pro 推广」开关。

## 四、重要说明：Windows 版原生能力

本机（macOS）交叉打包产出的 EXE 中，内嵌的原生模块仍为 macOS 架构二进制：

- `rust/build/shotscript_license.node` → Mach-O arm64（Windows 上无法加载）
- 本地 AI 推理引擎原生二进制 → arm64 预编译（Windows 上无对应二进制）

因此该 EXE 在 Windows 上运行时：
- **Pro 激活校验不可用**：Rust 模块加载失败，激活返回「激活校验模块加载失败」（应用不崩溃，优雅降级）；
- **本地 AI 润色不可用**：推理引擎加载失败后自动降级为「模拟引擎」（仅走通链路，无真实推理）。

**如需功能完整的 Windows 版，必须在 Windows 机器上重新构建打包**（见下方「五、Windows 正式打包」）。

## 五、Windows 正式打包（在 Windows 机器上执行）

### 环境要求
- Windows 10/11 x64
- Node.js 18+ 与 npm
- Rust 工具链（含 MSVC 目标）与 `napi-rs` CLI：`npm i -g @napi-rs/cli`
- 构建工具：`npm i -g windows-build-tools` 或安装 Visual Studio Build Tools（C++ 桌面开发）

### 步骤

```bash
# 1. 拉取代码
git clone <你的仓库地址> shotscript && cd shotscript

# 2. 安装依赖（npm 自动按平台拉取对应原生二进制）
npm install

# 3. 重新构建 Rust 激活模块（Windows x64）
cd rust
cargo build --release -p shotscript-tool
cp keys/public.pem crates/native/src/public_key.pem   # 若公钥有更新
cd crates/native
napi build --release --platform --arch
cp ../../target/release/shotscript_license_native.dll ../../build/shotscript_license.node
cd ../..

# 4. 打包 Windows 安装包
npm run dist:win
```

> 本地 AI 推理引擎的原生依赖通过 optionalDependencies 按平台声明，
> 在 Windows 上执行 `npm install` 会自动安装对应平台预编译二进制，无需手动指定。

## 六、未签名说明（两个平台）

- **macOS**：未签名应用首次打开会触发 Gatekeeper 拦截，需按「二、3」指引右键打开放行。如需彻底消除提示，
  需注册 Apple Developer Program（$99/年）并对产物做签名与公证（见「七」）。
- **Windows**：未签名安装包会触发 SmartScreen 警告，需手动「仍要运行」。若要消除警告，
  需购买代码签名证书（OV/EV）对 EXE 签名。

## 七、后续可选路线（$99 公证与自动更新）

> 用户当前决策：不购买 Apple 证书，走免费分发 + Gatekeeper 安装指引。以下为可选升级路线。

### macOS 公证（消除 Gatekeeper 弹窗）
1. 注册 Apple Developer Program（$99/年）；
2. 申请 Developer ID Application 证书并配置到 keychain；
3. 在 `package.json` 的 `build.mac` 中移除 `"identity": null`；
4. 重新 `npm run dist:mac`，electron-builder 自动签名 + 公证。

### 自动更新
- 引入 `electron-updater`，配置发布服务器（GitHub Releases / 自建）与 `publish` 字段；
- 签名/公证是 macOS 自动更新生效的前提之一（未签名应用通常只能手动更新）。

## 八、纯净模式使用提示

- 开关位置：设置页「隐藏 Pro 推广」；
- 行为：开启后隐藏全部 Pro 推广触点（导航入口、角标、升级弹窗、Pro 介绍区块），Pro 功能锁定；
- 已激活用户不受影响（已激活时纯净模式不生效，保持功能完整展示）；
- 持久化：localStorage 保存，重开应用保持。

---

## 九、构建产物目录说明

- `dist/`：最终分发包（DMG / EXE / blockmap）；
- `dist/mac-arm64/`：macOS 解包应用（`.app`），含 `app.asar.unpacked` 中的原生依赖；
- `dist/win-unpacked/`：Windows 解包目录（正式交付以 EXE 安装包为准）。

> 打包配置位于 `package.json` 的 `build` 字段；`files` 白名单已确保
> `rust/keys`、`rust/target`、`screenshot-*.png` 等敏感/临时文件不进入产物。
