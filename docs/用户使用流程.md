
# ShotScript 剧本工坊 · 用户使用流程（全流程手册）

> 面向视频创作者的 AI 文案工具 · 双版本说明 + 纯净模式取舍逻辑
> 本文档覆盖「获取安装 → 首启引导 → 免费体验 → 纯净模式 → 激活与 Pro 使用 → 授权管理」六个阶段。

---

## 一、获取与安装

### 1.1 版本形态

| 版本 | 范围 | 授权方式 | 目标用户 |
|------|------|----------|----------|
| **免费开源版** | 固定模板 / 精简算法 / 规则分镜 | 免费分发（无公证，走安装指引） | 普通创作者、预算有限用户 |
| **付费闭源 Pro 版** | 种子引擎无限模板（含黄金 3 秒钩子强度体系）/ 本地 AI 润色 / 多平台批量导出 | 激活码（Rust 原生 RSA 签名校验） | 深度创作者、需要批量产能的用户 |

### 1.2 安装方式（Apple 公证说明）

应用采用**免费分发**方式，未做 Apple 公证（不支付公证费用）。首次打开时系统可能提示"无法验证开发者"，按以下指引放行：

- **macOS**：右键应用图标 → 选择「打开」→ 在弹出确认框中点击「打开」。若仍被拦截，进入「系统设置 → 隐私与安全性」→ 点击「仍要打开」。
- **Windows**：SmartScreen 提示时点击「更多信息 → 仍要运行」。
- 应用为便携式/本地工具，运行无需联网，安全可信任。

## 二、首启引导

1. 首次启动进入**固定模板页**，侧边栏包含六个导航项：固定模板 / 精简压缩 / 规则分镜 / **无限模板(Pro)** / **本地润色(Pro)** / 设置 / 关于。
2. 侧边栏中带 `Pro` 徽标的两项（无限模板、本地润色）为付费功能入口；顶部含「升级 Pro」按钮。
3. 首次启动处于**未激活**状态：点击任意 Pro 入口会看到"Pro 专属，请升级"门控遮罩，同时弹出升级说明弹窗。
4. 关于页展示本应用版本、授权信息与 Pro 功能简介。

> 首启无强制登录、无弹窗轰炸，可立即使用免费三页（固定模板 / 精简压缩 / 规则分镜）开始创作。

## 三、免费体验

免费版本即可完成基础创作闭环，无需任何授权：

| 页面 | 能力 |
|------|------|
| **固定模板** | 面向抖音/B站/小红书/YouTube 的固定文案模板，填写占位符生成口播稿 |
| **精简压缩** | 将冗长文案精简压缩为短视频口播稿 |
| **规则分镜** | 按黄金 3 秒、节奏与镜头规则自动生成分镜脚本 |

免费体验流程建议：
1. 在「固定模板」选一个平台模板 → 填写关键占位符 → 生成口播稿 → 复制使用。
2. 用「精简压缩」把长文改写成口播体。
3. 用「规则分镜」把口播稿拆成可拍摄的分镜。

> 免费版无使用次数限制、无时间限制，可长期使用。

## 四、纯净模式（隐藏 Pro 推广）

### 4.1 什么是纯净模式

**纯净模式**是一个一键开关（默认关闭），面向**不想看到任何 Pro 推广内容**的免费用户：
开启后，全局隐藏所有 Pro 推广触点，界面回归纯粹的免费工具体验。

### 4.2 开启方式

进入 **设置页 → 「隐藏 Pro 推广」开关**，打开即可。

### 4.3 开启后隐藏的内容

- 侧边栏导航中的 Pro 徽标与「无限模板 / 本地润色」两个 Pro 入口；
- 各 Pro 页面的未激活门控遮罩（不再出现"请升级"遮罩）；
- 顶部的「升级 Pro」按钮与任何升级 / 推广弹窗；
- 关于页中的 Pro 介绍与推广文案。

### 4.4 纯净模式下的关键行为（取舍逻辑）

| 行为 | 说明 |
|------|------|
| **Pro 功能保持锁定** | 无限模板、本地润色、多平台导出在纯净模式下**不可用**（入口隐藏，无法触发），不会因隐藏而误开放 |
| **激活入口低调保留** | 纯净模式不提供"升级"入口，但**设置页保留低调的激活码输入框**，供已持有激活码的用户直接解锁 |
| **开关持久化** | 开关状态保存在本机（localStorage），与激活状态**相互独立**；重启应用后保持上次选择 |
| **一键恢复** | 关闭开关即恢复全部 Pro 推广触点与门控遮罩 |
| **已激活用户兼容** | 已激活用户开关无实际影响：激活状态下本就不显示推广，开关保留但不起作用，避免干扰 |

### 4.5 纯净模式的取舍设计

- **免费用户的诉求**：不想被付费功能打扰，希望工具界面干净、专注创作 → 纯净模式满足"无打扰"。
- **产品的诉求**：付费功能必须保持"可被发现、可被解锁" → 纯净模式只隐藏推广触点，不隐藏激活能力。
- **平衡点**：纯净模式下 Pro 入口与弹窗全部消失，但设置页仍可输入激活码。即"不打扰，但给钥匙"。

## 五、激活与 Pro 使用

### 5.1 获取激活码

Pro 激活码由开发者本机离线签发（Rust RSA-SHA256 数字签名，见 `docs/激活体系_RustRSA.md`）。联系开发者购买 Pro 版后获得一串激活码字符串。

### 5.2 输入激活码的入口（两种）

| 入口 | 位置 | 说明 |
|------|------|------|
| 升级弹窗 | 顶部「升级 Pro」按钮 / 任意 Pro 页门控遮罩按钮 | 默认（非纯净模式）入口 |
| 设置页激活框 | 设置页底部「激活码」输入框 | **纯净模式下依然可达**，外观低调、不构成广告 |

### 5.3 激活步骤

1. 复制激活码；
2. 打开任一激活入口，粘贴激活码并点击「激活」；
3. 应用通过 Rust 原生模块验签（防篡改、防伪造、校验有效期）；
4. 校验通过 → 侧边栏 Pro 入口点亮、门控遮罩解除，全部 Pro 功能立即可用。

### 5.4 Pro 功能一览

| 功能 | 说明 |
|------|------|
| **无限模板（种子引擎）** | 基于种子引擎无限生成平台适配模板，含黄金 3 秒钩子强度体系与四维质检 |
| **每日生长** | 模拟批量生成并沉淀通过质检的新模板 |
| **多平台批量导出** | 将模板池批量导出为 txt / markdown / srt 等格式 |
| **本地 AI 润色** | 本地模型润色文案（下载后离线推理，支持流式渲染与对照） |

## 六、授权管理

### 6.1 授权状态查看

- **关于页**：「Pro 授权」区块展示当前授权用户与有效期。
- **设置页**：同样展示授权状态（用户、有效期），与关于页同步。

### 6.2 授权机制

- 激活成功后在本地持久化授权文件（`userData/license.json`），下次启动自动复验（验签 + 有效期检查）。
- 过期 / 篡改 / 密钥不匹配 → 自动清除授权并回退为未激活状态，需重新激活。
- **不可转借**：激活码与用户身份（uid）绑定，且由私钥离线签发，无法伪造或续期。

### 6.3 常见问题

| 问题 | 处理 |
|------|------|
| 激活提示"激活码无效或已被篡改" | 检查是否复制完整（含首尾字符），重新粘贴后再试 |
| 激活提示"已过期" | 联系开发者续期（需重新签发激活码） |
| 纯净模式下找不到激活入口 | 进入设置页底部，激活码输入框仍保留 |
| 已激活但不想看到 Pro 推广 | 激活状态下本就不显示推广；开关保留但不影响已激活用户 |
| 重新安装 / 换电脑 | 原激活码可再次激活（同一用户），但旧设备本地授权会被新激活覆盖 |
